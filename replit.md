# Programadores para la Paz - Semana 2 Día 5

## Project Overview
A static educational web project for the "Programadores para la Paz" program. Contains a community participation form ("Formulario Participa") built with plain HTML5 and CSS3.

## Project Structure
- `semana2/index.html` - The main HTML form page
- `semana2/styles.css` - Stylesheet for the form
- `semana2/checklist-accesibilidad.txt` - Accessibility checklist for students
- `semana2/reflexion-verificacion.txt` - Reflection document on responsible verification
- `instrucciones/guia-practica-semana2-dia5.txt` - Practical guide for students

## Running the App
- Served via Python's built-in HTTP server on port 5000
- Command: `python3 -m http.server 5000 --directory semana2`

## Deployment
- Type: Static site
- Public directory: `semana2`
